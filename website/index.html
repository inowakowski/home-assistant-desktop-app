What it does

  • Reports the computer's state

    Whether the screen is on, the session locked, somebody at the keyboard; what is playing; whether the microphone or camera is in use; battery, network, disks and more.

  • Takes commands

    Volume and mute, media keys, the display, lock, sleep, shut down and restart, all from Home Assistant.

  • Shows notifications

    Sent from Home Assistant; on Windows and Linux with pictures and buttons that start automations.

  • Your own sensors and buttons

    Without writing code: whether a program runs, whether a dock is connected, the output of a PowerShell or shell command, a button that starts a program or presses keys.

  • Quick actions

    Start automations from the menu of HADA's icon, in the tray or the menu bar, or with a keyboard shortcut.

  • Your dashboard at hand

    Your Home Assistant dashboard, opened from HADA's icon: in a small window on Windows, in the browser on Linux and macOS.

How it is built

  • A service and a small app

    The service keeps the connection; the app beside it adds what only a signed-in user's desktop can tell. On Windows the service works with nobody signed in; on Linux and macOS it runs in your session, without root.

  • Light

    About 15 MB of memory for the service and 20 to 25 MB for the tray app, measured on Windows. The window only exists while it is open.

  • MQTT discovery

    The computer shows up in Home Assistant as a device with all its entities; nothing to write in YAML. A direct WebSocket connection works too.

  • Yours to control

    Every entity has a switch. The buttons that switch the computer off stay off until you turn them on. On Windows only an administrator can change settings.

Start here

  • Install HADA

    On Windows run the installer, or unpack the portable version, which needs no administrator rights. On Linux and macOS take the package for your system.

  • Connect it to Home Assistant

    Open HADA from its icon and set up a connection to your MQTT broker or straight to Home Assistant.

  • Use it in automations

    Dim the lights when a film starts, switch the desk lamp off when you lock the computer.
